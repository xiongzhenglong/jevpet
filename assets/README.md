# Assets

资产目录将在 Flutter 项目初始化后按类型拆分，例如：

```text
assets/
├─ pet/
├─ room/
├─ items/
├─ audio/
├─ references/
└─ manifests/
```

所有可由 Planner 调用的动画、声音和物品都应登记稳定 ID，不能依赖文件名猜测能力。

正式资产加入仓库前，应确认来源、授权、尺寸、帧率和导出规则。生成式资产也要保留提示词与版本信息，便于重做和风格统一。

`references/` 只保存产品与美术方向参考。参考图不能被代码作为运行时资产依赖，除非它经过正式切图、压缩、授权确认并移动到对应资产目录。
